# 功能清单

这是一个以图片生成为核心的工作台，提供两种用法：**纯生图**与**带 Agent 的生图**；画布只承载图片工作流。视频、音频、分镜脚本、时间线、导演台、短剧流程、任务中心、用量统计和插件市场已从代码中移除，不再作为隐藏开关保留。

## 页面入口

侧栏只有六个入口，全部对应真实路由：

| 入口 | 路由 | 作用 |
| --- | --- | --- |
| 生图 | `/generate/image` | 纯生图：填提示词和参数直接生成，查看历史与结果 |
| Agent 生图 | `/agent` | 带 Agent 的生图：用对话提出需求，助手读写入画布并执行生图 |
| 画布 | `/canvas`、`/canvas/:id` | 图片节点画布工作区 |
| 图片素材 | `/assets` | 工作区素材库 |
| 设置 | `/settings` | 模型渠道、密钥、外观、运行时策略 |
| Agent 技能 | `/skills` | 助手可调用的技能库 |

`/` 重定向到生图页；`/projects`、`/project`、`/projects/:id`、`/project/:id` 重定向到对应画布。其余路径落到 404。

## 画布节点类型

画布只注册四种内置节点，其他类型的历史节点只读保留、不再渲染也不可写入：

- **图片**：承载生成结果或上传素材，可作为后续生图的参考图。
- **提示词**：手写图片提示词、创意说明和备注，不执行文本生成。
- **生图配置**：为连线到它的图片节点提供共享模型与参数。
- **分组**：把相关节点组织在同一区域。

打开旧画布时，视频、音频、脚本等历史节点不会出现在画布中；保存时也不会写回。

## 生图

生图页和画布共用同一套模型与参数解析：选模型、填提示词、调整尺寸/质量/数量和参考图后提交，结果进入素材库与画布。失败会给出可执行原因，例如参考图数量超出模型上限、尺寸不被模型支持、渠道鉴权失败。

画布上的图片节点可以从连线读取提示词和参考图，也可以直接用节点面板放大编辑提示词。

## Agent

Agent 通过官方 pi SDK 宿主运行，读取和修改当前画布。助手可以查看画布结构、执行受权限范围约束的写操作、在画布上生成图片。权限模式、会话历史和操作回执由后端持久化。

## 画布保存保护与版本记录

旧页面或旧缓存不能覆盖云端新内容。每次内容保存核对服务端版本，发生冲突会停止该画布自动提交并保留本地草稿；平移、缩放和打开画布不触发整份内容保存。画布顶部显示保存状态，可保留草稿后加载云端最新版。

「版本记录」按日期展开历史树，小屏使用抽屉。点击版本进入独立只读预览，可以缩放查看或下载；返回当前画布后继续编辑。恢复历史会先保存本地草稿、备份当前云端内容，再创建一个新版本。普通快照最短间隔 5 分钟，每个画布保留最近 20 份。

## 画布智能引用

节点提示词面板提供「智能引用」入口，支持 AutoLink 开关和「一键引用全文」。输入已连接素材的名称、标签或素材栏序号后，按 Tab 或点击光标旁的候选项插入引用。匹配仅覆盖当前已连接且激活的图片与文本素材。

## 提示词放大编辑

图片节点的提示词面板支持放大编辑：窗口默认约 `min(1200px, 92vw)`，编辑区最小高度 200px，右下角可对角拖拽，方向键可微调。切换节点后尺寸恢复默认，节点上的紧凑面板外观不变。

## 画布交互

- 普通鼠标滚轮以鼠标位置为中心缩放；触控板滚动和水平滚动保留平移行为。
- 双击空白处打开创建菜单；框选支持替换、追加、切换和减去四种策略。
- 节点和画布快捷键集中在画布快捷键弹层，输入框内不抢占按键。

## 接入自己的模型服务

在设置的「模型服务」中添加 OpenAI、Google Gemini、火山方舟或兼容服务，填写地址与 API Key 后读取模型目录。可以搜索、按用途筛选，也可以手动添加服务商提供的模型 ID。只有保存后才启用服务。

每个模型可配置用途、协议与参数，用途目前只有「文本」和「图片」。重新读取目录保留已选模型和手动配置；目录里出现模型不等于已验证可生成。模型测试会提示供应商费用，并等待任务完成后显示结果。

## 工作区账号容量

登录后，侧栏用户头像上方显示账号文件容量进度。用量达到 70% 变为警告色，达到 90% 或已满变为危险色。点击进入素材库。

- `web/src/components/layout/workspace-sidebar-storage-meter.tsx`：侧栏容量进度。

## 已移除的能力

以下能力已从代码、路由、接口和画布节点类型中彻底删除：

- 视频、音频生成与它们的模型能力、请求协议和轮询策略。
- 分镜脚本、批量创作表、时间线、字幕、转写、深度捕捉、播放缓存和视频剪辑导出。
- 导演台、短剧项目流程、创作会话（creation run）、聊天页和文本任务流式输出。
- 任务中心、用量统计、插件市场与 AI 审美批改插件。
- 独立的视频/音频设置面板和对应的节点级参数。

历史数据仍可读取，但相关节点只读、不再渲染，也不能通过任何写入路径重新创建。
